# Neon Genesis Evangelion
A hyprland based NGE (Neon Gensis Evangelion) rice.
The depemdencies are hyprland waybar fastfetch alacritty and cava.
the configs have to go in the .config folder on your pc.
have fun uing it :3
![a picture os the rice with som eapplications open]()

## Instaltion
the instaltion only works for arch linux right now.
to install this repo run this command:   
git clone https://github.com/catcloude/nge_cat.git && cd nge_cat && chmod +x install.sh && chmod +x ./dashboard.sh && ./install.sh

## a quick note
the fastfetch config is not named right i intended to have it run by fast-hypr. 
if you want to do this yourself then edit the rc file (eg. .bashrc) of the shell you are using and add alias fast-hypr="fastftech -c ~/.config/fastfetch/fasteftch.jsonc".
reboot the terminal and it will run.
